# 页面覆盖：错题本（mistakes）

基于 MASTER.md，以下为本页专属规则：

- 入口：侧边栏「错题本」（mdi:format-list-bulleted），数据经 `trigger_command("grading::list")`。
- 布局：学科筛选 chips（全部/各学科）+ 响应式卡片网格（minmax 320px）。
- 卡片：**标题（一句话，15px/700，单行省略）**、学科徽章（teal）、知识点徽章、题目（Markdown/KaTeX，2 行截断）、学生作答、参考答案、错因分析、时间。
- 标题规则：判分归档时由模型生成（≤16 字，概括考点或错因），存在 `Mistake.title`；**存量错题没有该字段，回退显示「学科 · 知识点」**——两种形态都必须是单行，高度不变，否则网格里的卡片会参差不齐。编辑弹窗里可改（留空 = 清空并回退）。
- 作答条（`.answer-strip`）：你的作答 / 参考答案压成一行，超出部分省略号截断。两个文本段走 `v-html-smiles` 渲染（`$x^2$` 要出公式），但**不能加 `.md-body`**——它的 `white-space: normal` 会让整行换行、省略号失效；生成器包出来的 `<p>` 需摊平成 `display: inline`，公式字号压回条带的 13px。
- 空状态：笔记本图标 + 引导文案；加载态用旋转图标（mdi:loading）。
- 交互：hover 卡片轻浮起（200ms，translateY -2px）。
- 抽屉（点卡片打开）：顶部同样是标题 + 标签两段式，`order: -1` + `flex-basis: 100%` 让标题单独占一行排在标签之前（不必改头部的 wrap 结构）。
