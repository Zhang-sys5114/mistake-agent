# 审计默认全覆盖：任何操作都必须记录

审计是默认行为而非选择性功能。所有操作均记录：入口点调用（tool/command/event）、消息完成（按消息 id 引用会话文件）、编辑与切分支、会话切换与交接、记忆读写删、配置变更、LLM 调用（provider/model/token/耗时/结果）、compute 执行、kernel 生命周期（启动/关闭/崩溃）与越权拒绝。流式中间态（token 增量）不落审计，以完成后的消息为单位记录；审计记元数据与引用，不复制大内容（作业图片、完整回复）；compute 的验算代码与结果为例外，全量记录。写入方为 kernel，经 storage 服务持久化到数据根目录 audit/ 的追加式 JSONL，10MB 归档轮转。
