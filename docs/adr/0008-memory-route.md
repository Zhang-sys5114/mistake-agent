# 记忆路由：第三个内核插件，目录式浏览

记忆作为独立内核插件（ServiceId::Memory）实现，按层级路径组织（学科/知识点/条目）。工具集为 memory::save(path, content)（模型自动保存，用户也可显式调用）、memory::show(path?)（无参数列出全部条目名，带参数查看条目详情）、memory::remove(path)（强制参数，仅用户可调用）。上下文不自动注入记忆内容，只在系统提示中保留一行入口提示；路径由 LLM 生成，memory 内核插件负责路径校验（拒绝越界、绝对路径与非法字符）。记忆与 storage（结构化业务真相）、session（过程记录）职责分离，压缩摘要不自动灌入记忆。
