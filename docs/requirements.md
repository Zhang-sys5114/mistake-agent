# 需求分析（任务三·场景一）

> 依据《2026 项目实战任务书》任务 3 场景 1；本次实现范围**严格锁定场景一**，其余场景（薄弱点定位/复盘/考核/追踪）不在本期交付内。

## 1. 背景与用户

面向中学生的本地错题管理 + 辅助学习 Agent。用户将纸质作业/试卷拍照或扫描上传，系统自动识别题目与手写作答、自动判分、标注对错、绑定知识点，并把错题自动归档进个人错题本。

## 2. 功能清单

| 编号 | 功能 | 说明 | 状态 |
|---|---|---|---|
| F1 | 图片上传 | png/jpg/jpeg/webp/bmp，经 GUI 文件选择器或消息路径 | ✅ |
| F2 | 文本型 PDF 上传 | pdf-extract 提取文字；扫描版给出明确提示（拍照转图片） | ✅ |
| F3 | 自动识别题目与作答 | SiliconFlow Qwen3-VL-32B-Instruct 多模态 OCR（只提取不判分） | ✅ |
| F4 | 自动判分 + 标注对错 | 主模型 deepseek-v4-flash（Responses API + json_schema 严格输出）逐题判分 | ✅ |
| F5 | 绑定知识点 | 每题输出 knowledge_point | ✅ |
| F6 | 错题自动归档 | 错题写入错题本（本地 JSON 持久化），可查询 | ✅ |
| F7 | 错题本查询 | grading::list（可按学科/知识点过滤） | ✅ |
| F8 | 流式对话体验 | 打字机增量、思考过程折叠展示、工具进度、停止按钮 | ✅ |

## 3. 核心流程

```
用户（GUI）→ 发消息/选文件 → sidecar（stdio JSONL）→ SessionScheduler
  → AgentLoop（注入系统提示 + 工具列表）→ 主模型流式
  → 模型调用 grading::upload → 视觉模型 OCR → 主模型判分（json_schema）
  → 错题归档（storage 文件持久化）→ 事件流回 GUI（气泡/进度/思维链）
```

## 4. 非功能需求

- 本地优先：数据与 key 都在本机（~/Documents/.mistake-agent），无云端同步。
- 隐私：API key 仅存 settings.json，日志脱敏；不上传任何数据到除模型厂商外的服务。
- 安全：Markdown/LaTeX 渲染一律经 DOMPurify 净化（防 XSS）；CSP 收紧（script-src 'self'）；全栈无 XML 解析路径（PDF 走二进制解析器 lopdf，无 XXE 面）。
- 体验：流式输出不等待完整回答；回合中禁发消息，先停止再发送；思维链默认折叠。
- 容错：页级错误重试 2 次后记录继续；系统性模型错误（无余额/模型下架）直接告知不白跑。
- 护栏：工具级超时（默认 30s，可声明）/ 回合预算 10min / 同码连续失败 3 次停止 / 用户取消 SIGTERM→SIGKILL。

## 5. 本期边界（明确不做）

- 扫描版 PDF 渲染 OCR（需 poppler/mupdf，后续可选）。
- 手写公式/图形的鲁棒识别优化（模型能力随选型提升）。
- 场景二~五、compute::verify、消息树编辑/切分支、设置向导。
- Windows 安装包（当前非 Windows 环境，配置与步骤已在文档标注）。
